# MathLab

Тренировочная математическая библиотека на Python.

## О проекте

MathLab — это учебная библиотека для реализации математических объектов и алгоритмов с нуля.

Цель проекта:

- изучение разработки Python-библиотек;
- практика объектно-ориентированного программирования;
- написание тестируемого кода;
- изучение принципов проектирования программного обеспечения;
- подготовка основы для дальнейшего изучения математического моделирования и машинного обучения.

## Реализовано

### Vector

Класс `Vector` предназначен для работы с математическими векторами.

Поддерживаемый функционал:

- создание вектора из последовательности чисел;
- проверка корректности входных данных;
- проверка пустых векторов;
- получение элементов по индексу;
- получение размера вектора;
- сравнение векторов;
- сложение векторов;
- вычитание векторов;
- умножение вектора на скаляр;
- деление вектора на скаляр;
- изменение знака вектора;
- вычисление скалярного произведения;
- вычисление нормы вектора;
- вычисление расстояния между векторами;
- нормализация вектора.

## Обработка ошибок

Реализована обработка некорректных ситуаций:

- создание пустого вектора;
- передача данных неправильного типа;
- деление на ноль;
- операции между векторами разной размерности;
- передача некорректных типов данных.

## Тестирование

Для автоматического тестирования используется библиотека `pytest`.

Тесты покрывают:

- создание объектов;
- работу математических операций;
- корректность результатов;
- обработку исключений.

Запуск тестов:

```bash
pytest
